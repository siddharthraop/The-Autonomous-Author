Ship a feature. Get the docs draft.

Pick a sample feature, or write your own, and commit it. The agent reads the code change, finds every page it affects, drafts the update in docs as code (MyST Markdown) and DITA 1.3, checks every sentence against its source, and hands the draft to you for review. Then compare what it did with what a good draft should do.

This version drafts from a code change to its sample product, natctl, so choose a timeout and a change, then describe it in your words. Pasting a feature from another product isn't supported yet; see limitations.
